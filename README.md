# API Security Testing Project

## 🔐 Overview
This project demonstrates API security testing using Postman and Reqres API.

## 🛠 Tools Used
- Postman
- Reqres API

## 📌 Features Tested
- API Key Authentication
- Unauthorized Access Handling
- GET and POST Requests

## 🧪 Testing Results
- Without API Key → 401 Unauthorized
- With API Key → 200 OK

## 📂 Files Included
- API Security Report (PDF)
- Screenshots

## 🎯 Conclusion
The API enforces security using API keys and prevents unauthorized access.
